# Phase P05 — Acceptance Criteria: Public Services & Deterministic Task Guidance

## Acceptance Checklist

- [ ] **AC-P05-01:** Navigating to `/services` displays verified Maharashtra public services from `services.json`.
- [ ] **AC-P05-02:** Services can be searched by keyword (English and Marathi) and filtered by category.
- [ ] **AC-P05-03:** Clicking a service card navigates to `/services/:id`.
- [ ] **AC-P05-04:** Service detail page displays localized name, description, required documents, and verified steps.
- [ ] **AC-P05-05:** Task Journey step wizard allows clicking "Next Step" and "Previous Step" sequentially.
- [ ] **AC-P05-06:** The step wizard clearly indicates current active step (`●`), completed steps (`✓`), and upcoming steps (`○`).
- [ ] **AC-P05-07:** Document checklist checkboxes can be toggled by the user and persist in local state.
- [ ] **AC-P05-08:** Official source card renders the authoritative portal name and opens the verified government URL in a new tab.
- [ ] **AC-P05-09:** Switching language between English, Marathi, and Hindi updates all service strings dynamically without resetting the active step.
- [ ] **AC-P05-10:** No automatic form submission or automated backend form posting occurs.
