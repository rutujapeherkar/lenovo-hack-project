# Phase P06 — Acceptance Criteria: Scheme Finder & Eligibility Engine

## Acceptance Checklist

- [ ] **AC-P06-01:** Navigating to `/schemes` loads verified schemes from `schemes.json`.
- [ ] **AC-P06-02:** User can filter schemes by category tabs: All, Education, Agriculture, Disability/Divyang, Social Welfare.
- [ ] **AC-P06-03:** Free-text search input filters schemes by name, keyword, and description.
- [ ] **AC-P06-04:** Scheme cards render localized title, category tag, brief plain-language summary, and "View Details" button.
- [ ] **AC-P06-05:** Clicking a scheme card opens `/schemes/:id` showing complete details.
- [ ] **AC-P06-06:** Scheme detail page renders dedicated sections: Overview, Eligibility, Benefits, and Required Documents.
- [ ] **AC-P06-07:** The official source box renders the government authority, last verification date, and an authentic external link.
- [ ] **AC-P06-08:** Searching for an unknown or non-existent scheme displays a friendly empty state linking to myScheme.
- [ ] **AC-P06-09:** Zero AI-synthesized schemes or artificial URLs appear in search results.
- [ ] **AC-P06-10:** Language switcher updates scheme names and summaries dynamically across `en`, `mr`, and `hi`.
